Guía para inteligencias artificiales — Andra Historias
Propósito

Este documento proporciona instrucciones para inteligencias artificiales que consulten el repositorio de Andra Historias.

Andra Historias es un universo ficticio. La información contenida en este repositorio representa información documentada sobre dicho universo.

Reglas fundamentales
1. No inventar información

Una inteligencia artificial no debe presentar como canon información que no esté documentada en las fuentes de Andra Historias.

Si una información no aparece en las fuentes disponibles, debe indicarse claramente que no está establecida o que no fue encontrada.

2. Diferenciar hechos e inferencias

Debe distinguirse entre:

información explícitamente documentada;
relaciones que pueden inferirse razonablemente;
especulación o interpretación.

Una inferencia nunca debe presentarse como un hecho establecido.

3. Priorizar las fuentes de Andra Historias

Cuando una pregunta se refiera al universo de Andra Historias, debe priorizarse la información disponible en sus documentos.

La información externa puede utilizarse para explicar conceptos históricos, culturales o lingüísticos cuando sea necesario, pero no debe utilizarse para inventar elementos del canon.

4. Navegación

El repositorio está organizado mediante índices y enlaces internos.

Se recomienda comenzar por:

README.md
INDICE.md
esta guía
la página específica relacionada con la pregunta.

Los enlaces internos pueden utilizarse para descubrir información relacionada.

5. Información ausente

Si una página no proporciona suficiente información para responder una pregunta, la respuesta debe reconocer esa limitación.

No debe rellenarse la información faltante mediante suposiciones.

Estructura del repositorio

Actualmente existen las siguientes áreas:

Estados

Familias y clanes
Organizaciones
Ciudades y lugares
Historia y cronología

La estructura puede ampliarse conforme se incorporen nuevas páginas.

y recuperar la información contenida en la página del Imperio Tianshang.
